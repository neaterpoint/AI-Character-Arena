# AI Character Arena

Turn-based battles between any two characters, powered by AI.

## Run
```bash
# inside the activated virtual environment
pip install -r requirements.txt
streamlit run app.py
```

## AI status
The project runs in **placeholder mode** (fake AI responses) until a key is configured.
See the docstring at the top of `services/ai_client.py` for the 3 steps to go live.
